# DiceBattle con Flutter

PMDM · UD1 · A3. Proyecto generado con Flutter 3.47.5 y Dart 3.13.4 para Android.

Descomprime en una carpeta nueva y abre la raíz que contiene pubspec.yaml. Con el SDK acordado, ejecuta flutter pub get y selecciona un emulador Android en Android Studio. La primera apertura puede descargar dependencias: el entorno debe prepararse antes de clase.

La configuración generada utiliza Android compileSdk/targetSdk 36 y minSdk 24 con esta versión de Flutter, además de las herramientas indicadas en el registro docente. Utiliza la versión probada o valida expresamente cualquier cambio. No es una actualización automática del entorno del aula.

android/local.properties se genera localmente: este ZIP no incluye rutas del ordenador del docente. Se conservan el Gradle Wrapper, los archivos de configuración, fuentes y dependencias resueltas. No incluye SDK, emuladores ni directorios build.

## Proyecto inicial para el alumnado

Un jugador, nombre, dado, suma y pantalla final. No incorpora contador/límite, reinicio ni paso del contador: son los tres cambios de A3.
